PRUEBA DE TOLERANCIA A FALLOS: SE APAGA Fa0/24 EN SW-ACC-CORP-B
================================================================================

$ SW-ACC-CORP-B(config)# interface FastEthernet0/24
$ SW-ACC-CORP-B(config-if)# shutdown

Transicion observada paso a paso en Gi0/1:

    Gi0/1   Altn BLK  ->  Root LIS  ->  Root LRN  ->  Root FWD

$ SW-ACC-CORP-B# show spanning-tree vlan 16     (durante la transicion)
  Root ID    Cost        26
             Port        25(GigabitEthernet0/1)
Gi0/1            Root LIS 4         128.25   P2p

$ C:\> ping 192.168.16.11        (desde PC-GER-04, mientras Gi0/1 esta en LIS)
    Packets: Sent = 4, Received = 0, Lost = 4 (100% loss)

$ SW-ACC-CORP-B# show spanning-tree vlan 16     (ya convergido)
  Root ID    Priority    24592
             Address     0001.C94C.BC23
             Cost        26
             Port        25(GigabitEthernet0/1)

---------------- ---- --- --------- -------- --------------------------------

$ C:\> ping 192.168.16.11        (desde PC-GER-04, ya convergido)
Pinging 192.168.16.11 with 32 bytes of data:
Reply from 192.168.16.11: bytes=32 time=10ms TTL=128
Reply from 192.168.16.11: bytes=32 time<1ms TTL=128
Reply from 192.168.16.11: bytes=32 time<1ms TTL=128
Reply from 192.168.16.11: bytes=32 time<1ms TTL=128
    Packets: Sent = 4, Received = 4, Lost = 0 (0% loss)

    --> El enlace inter-alas pasa a ser el Root Port y entra en FORWARDING.
    --> El costo al root sube de 22 a 26 = 4 (Gi0/1) + 19 (Fa0/24 del ala A)
        + 3 (Po3): el trafico ahora rodea por el ala A.
    --> Se cumple el requisito del enunciado: "la conectividad entre ambas alas
        debe mantenerse activa incluso si la ruta hacia el switch de distribucion
        mas cercana queda inhabilitada".
    --> IMPORTANTE: durante la transicion el ping SI falla. PVST tarda dos veces
        el forward delay (15 s + 15 s) en llevar un puerto de bloqueo a reenvio.
        Ese intervalo de corte es el precio de PVST frente a Rapid-PVST, y es la
        diferencia con la prueba de EtherChannel de la evidencia 02, donde no
        hubo corte alguno.
